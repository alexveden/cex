# Cex.C Standard Library


## Namespace list
* `json/` - streaming JSON reader/writer implementation, with `json.gen` for automatic code generation for serialization/deserialization between C-structs and JSON
* `Random/` - Random number generator (experimental)
* `testing/` - advanced unit-test utilities
* `testing/coverage/` - `./cex coverage run/report/clean` build-system command for test coverage (gcc/gcov, clang/llvm-cov)
* `fsm/` - final state machine implementation (experimental)
