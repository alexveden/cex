     133              : ## CEX Exception-based error handling.
     134              : 
     135              : Errors are `char*` pointers:
     136              : - `EOK` (or `Error.ok`) = `NULL` → success
     137              : - Any non-NULL value → an error
     138              : - `Exception` return type forces the caller to check (`warn_unused_result`)
     139              : - Errors are compared by **address**, never by string content
     140              : 
     141              : 1. **Unambiguous** — only two states: OK or error, never mixed with valid return values
     142              : 2. **General purpose** — same pattern for allocation errors, IO, argument validation, etc.
     143              : 3. **Easy to report** — errors are printable strings; use `e$raise` to tag the origin location
     144              : 4. **Bubbling up** — pass the same error pointer upward; no error-code translation needed
     145              : 5. **Extensible** — define custom error structs with your own string constants
     146              : 6. **Low overhead** — one pointer (one register), comparison is a single instruction
     147              : 7. **Natural** — regular `if` works; `e$` macros are optional helpers
     148              : 8. **Mandatory checking** — `Exception` return type triggers `-Werror=unused-result` if ignored

     269              : ### Tracebacks
     270              : 
     271              : `e$` macros record a traceback instead of printing it immediately. Verbosity is a
     272              : compile-time knob `CEX_TRACEBACK_VERBOSITY` (0..3, default 2):
     273              : 
     274              : | Level | Behavior                                              |
     275              : | ----- | ----------------------------------------------------- |
     276              : | 0     | No tracebacks, ring disabled (`e$traceback_len == 0`) |
     277              : | 1     | Ring records `{err, file, line}`                      |
     278              : | 2     | Ring records `{err, file, func, msg}` (default)       |
     279              : | 3     | Immediate logging to stdout, no ring                  |
     280              : 
     281              : Buffered levels (1, 2) are not printed automatically. Flush the ring at the top-level
     282              : sink when `main()` gets a non-`EOK` result:
     283              : 
     284              : ```c
     285              : int
     286              : main(int argc, char** argv)
     287              : {
     288              :     e$except (err, app_main(argc, argv)) {
     289              :         e$traceback_print(stderr);
     290              :         return 1;
     291              :     }
     292              :     return 0;
     293              : }
     294              : ```
     295              : 
     296              : Ring capacity is `CEX_TRACEBACK_CAP` (default 32 frames): the oldest frames are kept
     297              : and extra ones are dropped. Traceback read-back API:
     298              : 
     299              : - `e$traceback_print(stream)` — print all recorded frames to a `FILE*`
     300              : - `e$traceback_arr` — recorded frames array, use with `for$each`/`for$eachp`
     301              : - `e$traceback_len` — number of recorded frames
     302              : - `e$traceback_reset()` — drop all recorded frames
     303              : 
     304              : A frame prints as `#N (file:line func()) [err] msg` at level 2, and as
     305              : `#N (file:line) [err]` at level 1. `e$raise(err, "msg")` requires the message to be a
     306              : string literal.
