      36              : This is a full sprintf replacement that supports everything that
      37              : the C runtime sprintfs support, including float/double, 64-bit integers,
      38              : hex floats, field parameters (%*.*d stuff), length reads backs, etc.
      39              : 
      40              : It compiles to roughly 8K with float support, and 4K without.
      41              : As a comparison, when using MSVC static libs, calling sprintf drags
      42              : in 16K.
      43              : 
      44              : 
      45              : FLOATS/DOUBLES:
      46              : ===============
      47              : This code uses a internal float->ascii conversion method that uses
      48              : doubles with error correction (double-doubles, for ~105 bits of
      49              : precision).  This conversion is round-trip perfect - that is, an atof
      50              : of the values output here will give you the bit-exact double back.
      51              : 
      52              : If you don't need float or doubles at all, define STB_SPRINTF_NOFLOAT
      53              : and you'll save 4K of code space.
      54              : 
      55              : 64-BIT INTS:
      56              : ============
      57              : This library also supports 64-bit integers and you can use MSVC style or
      58              : GCC style indicators (%I64d or %lld).  It supports the C99 specifiers
      59              : for size_t and ptr_diff_t (%jd %zd) as well.
      60              : 
      61              : EXTRAS:
      62              : =======
      63              : Like some GCCs, for integers and floats, you can use a ' (single quote)
      64              : specifier and commas will be inserted on the thousands: "%'d" on 12345
      65              : would print 12,345.
      66              : 
      67              : For integers and floats, you can use a "$" specifier and the number
      68              : will be converted to float and then divided to get kilo, mega, giga or
      69              : tera and then printed, so "%$d" 1000 is "1.0 k", "%$.2d" 2536000 is
      70              : "2.53 M", etc. For byte values, use two $:s, like "%$$d" to turn
      71              : 2536000 to "2.42 Mi". If you prefer JEDEC suffixes to SI ones, use three
      72              : $:s: "%$$$d" -> "2.42 M". To remove the space between the number and the
      73              : suffix, add "_" specifier: "%_$d" -> "2.53M".
      74              : 
      75              : In addition to octal and hexadecimal conversions, you can print
      76              : integers in binary: "%b" for 256 would print 100.
