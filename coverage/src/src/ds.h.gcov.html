     376              : ## Iteration
     377              : 
     378              : Unified array / hashmap / slice iteration framework.
     379              : 
     380              : `for$` macros provide a single syntax for looping over any iterable data in CEX:
     381              : 
     382              : | Variant                              | Copies elements?          | Use case                                         |
     383              : |--------------------------------------|---------------------------|--------------------------------------------------|
     384              : | `for$each(it, array, len?)`          | By value (≤ 64 B)         | Small types / copy iteration / slices            |
     385              : | `for$eachp(it, array, len?)`         | By pointer (no copy)      | Large structs / avoid copy overhead / slices     |
     386              : | `for$iter(T, it, iter_func)`         | Custom (cex_iterator_s)   | Tokenizers, generators, splitters                |
     387              : 
     388              : `for$each` and `for$eachp` work identically on `arr$`, `hm$`, static C arrays, and pointer+length slices.
     389              : 
     390              : ### Examples
     391              : 
     392              : - Using for$ as unified array iterator
     393              : ```c
     394              : arr$(int) array = arr$new(array, mem$);

     397              : // for$each copies elements by value (up to CEX_FOREACH_MAX_COPY_SIZE bytes)
     398              : for$each (it, array) {
     399              :     io.printf("el=%d\n", it);
     400              : }

     402              : // for$eachp provides a pointer — no copy, prefer for large structs
     403              : for$eachp (it, array) {
     404              :     // TIP: derive index from pointer subtraction
     405              :     usize i = (usize)(it - array);
