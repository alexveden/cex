     373              : ## Iteration
     374              : 
     375              : Unified array / hashmap / slice iteration framework.
     376              : 
     377              : `for$` macros provide a single syntax for looping over any iterable data in CEX:
     378              : 
     379              : | Variant                              | Copies elements?          | Use case                                         |
     380              : |--------------------------------------|---------------------------|--------------------------------------------------|
     381              : | `for$each(it, array, len?)`          | By value (≤ 64 B)         | Small types / copy iteration / slices            |
     382              : | `for$eachp(it, array, len?)`         | By pointer (no copy)      | Large structs / avoid copy overhead / slices     |
     383              : | `for$iter(T, it, iter_func)`         | Custom (cex_iterator_s)   | Tokenizers, generators, splitters                |
     384              : 
     385              : `for$each` and `for$eachp` work identically on `arr$`, `hm$`, static C arrays, and pointer+length slices.
